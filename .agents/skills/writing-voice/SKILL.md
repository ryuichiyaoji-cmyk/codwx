# 写作风格提取

**核心原则：风格只能从真实语料里提取，问不出来。**
问"你想要什么风格"，答案通常是"专业但不失亲和"——这种描述无法执行。但语料里藏着具体习惯：句多长、爱用什么标点、怎么开场、什么时候加括号吐槽。

**架构参考**：`xhs-photo-style`（从参考样本提取风格卡 → 存储 → 复用到新产物）。本技能是它的写作版。

## 四轮提取流程

### 第 1 轮 · 收语料

向用户要 **3–5 段他本人写的文字**，任何体裁都行：

- 以前写的文章片段（**必须是 AI 没改过的**）
- 朋友圈、微信聊天、给同事的邮件
- 在评论区跟人争论的话（**这种最暴露真实风格**）

每段 200 字以上。请用户标出**哪段他自己最满意**——那段的权重最高。

**不要跳过这一轮。** 没有语料就停止，不要靠提问硬凑。

### 第 2 轮 · 机器分析 + 对照诊断

1. 对语料跑 `python3 tools/voice_check.py <语料文件>`，拿到客观指标基线
2. 对**现有草稿**跑同一脚本，逐项对比
3. 产出差异清单：**"你的语料是 X，草稿是 Y"**，只列差异，不列评价

**必须落到具体数字与具体词**，禁止写"草稿比较生硬"这类无法执行的话。

### 第 3 轮 · 边界追问（只问 5–8 个，都能一句话答）

语料里看不出来的部分必须问。**固定问这七个**：

1. 哪些词你**绝对不用**？（列出来进禁用词表）
2. 能用网络梗 / 谐音吗？用的话举一个你常用的
3. 会骂人或阴阳怪气吗？（决定情绪档位的上限）
4. **"小编"这个自称保留，还是改"我"？**
5. 举例时你更爱用"具体的人/公司"，还是"抽象的场景"？
6. 写错了会承认吗？会公开改口吗？
7. 你最讨厌哪一类公众号文章？（反例比正例更好用）

### 第 4 轮 · 盲测收敛

1. 用提取出的风格卡，**重写草稿里的某一段**（内容、观点完全不动）
2. 只把结果给用户看，问一句：**像不像你写的？**
3. 不像 → 用户指出"哪一句不像" → 改风格卡对应字段 → 再测
4. 一般 2–3 轮收敛；收敛前不要宣布完成

## 风格卡的字段（必须全部填，且全部可检验）

写入 `voice/风格卡.md`。**每一栏都要能被第三方拿着去核对**：

| 字段 | 写什么 | 反例（不许这样写） |
|---|---|---|
| 句长 | 平均 X 字；短句（<15 字）占比 Y% | "句子比较有节奏" |
| 人称 | "我/我们"每千字 N 次；用不用"小编" | "比较亲切" |
| 标点习惯 | 破折号 N 次/千字、省略号、括号 OS 用法 | "标点丰富" |
| 开场方式 | 场景起 / 数字起 / 提问起，任选并举例 | "开场有吸引力" |
| 收尾方式 | 回扣 / 提问 / 金句 / 自嘲，任选并举例 | "结尾有力" |
| 情绪档位 | 有/无吐槽；有/无自嘲；强度 1–3 | "情绪克制" |
| 口语词表 | 具体词表（挺/其实/说白了…） | "口语化" |
| **禁用词表** | 用户点名不用的词 + 机器检出他从不用的 AI 腔词 | "避免生硬" |
| 举例习惯 | 人名/公司/生活场景的比例 | "例子生动" |
| 典型段长 | X–Y 字，段间差异来自哪 | "段落灵活" |

## 风格会漂移，要定期回填

- 每发布 5–10 篇，把新文章加进 `voice/语料/`，重跑第 2 轮，看基线有没有漂
- 风格卡改动**留痕**（在卡片底部记"YYYY-MM-DD 改了什么、为什么"）
- 只有用户明确说"以后就这么写"才改卡，不要自己悄悄调

## 与其它技能的接口

| 技能 | 关系 |
|---|---|
| `ai-article-writer` | **写作前必读 `voice/风格卡.md`**；风格卡是硬约束，不是参考 |
| `ai-article-formatter` | 不管风格（只管呈现） |
| `tools/voice_check.py` | 本技能的检测工具，也是发布前自检的一项 |
| `tools/preflight.py` | 已含部分 AI 味检测；风格卡建立后以 `voice_check.py` 的对比结果为准 |

## 红线

- **不替用户发明风格**：语料里没有的特征不许写进风格卡
- **不拿别人的语料**：必须是用户本人写的
- **不改内容只改表达**：盲测重写时观点、事实、结构都不动
- 用户说"这样不像我"时，**以用户的判断为准**，不要用机器指标反驳他
