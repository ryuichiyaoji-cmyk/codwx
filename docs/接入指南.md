# 接入指南：换成你自己的账号

这套系统默认绑定本号这个号。想让它在你的号上跑，**只需要改三处**，
其余（技能、工具、评分口径、红线）都能直接用。

---

## 一、必改的三处

### 1. 账号状态块 `account-status.md`

复制模板改名：

```bash
cp .agents/skills/_shared/account-status.template.md account-status.md
```

填当前阶段、目标、历史爆款、基线字段。**这个文件已 gitignore，不会进仓库**（含收入数据）。

两条规则：
- **状态块里没有的账号数字，一律不引用、不推测**
- 超过 7 天没更新，`draft_kit.py brief` 会主动报警

### 2. 个人风格卡 `voice/风格卡.md`

这是整套系统里**最需要你亲手做**的一步。方法：

```bash
# ① 把你自己写的 3–5 段文字（不要用 AI 写的）放进 voice/语料/
#    每段单独一个 .md 文件
# ② 建客观基线
python3 tools/voice_check.py --corpus voice/语料 --save voice/基线.json
# ③ 体检任意一篇稿
python3 tools/voice_check.py topics/草稿-xx.md --baseline voice/基线.json
```

然后照着 `voice/风格卡.md` 的十个字段填：句长 / 人称 / 标点习惯 / 开场方式 / 收尾方式 /
情绪档位 / 口语词表 / 禁用词表 / 举例习惯 / 典型段长。

**最重要的建议**：用**盲测**代替问答。把同一段给三个版本（AI 腔版 / 全照口语版 / 中间路线），
让你自己选。这比逐条问你"爱用什么标点"有效得多——本项目当初就是靠一次盲测
定下了"要结构感 + 人话"这个基调。

改卡规则：**只有你明确说"以后就这么写"才改**，每次改动在末尾记「日期 + 改了什么 + 为什么」。

### 3. 微信发布凭据 `~/.workbuddy/.env`

```bash
cat > ~/.workbuddy/.env <<'EOF'
WX_APPID=你的AppID
WX_APPSECRET=你的AppSecret
EOF
chmod 600 ~/.workbuddy/.env
```

**这个文件永远不要进仓库**，脚本也不会打印它的内容。

发布前还要在微信后台把**出口 IP 加进白名单**（IP 会轮换，一次多留几个）。
报错对照：`40164` = IP 没放行（换 secret 无用）；`40125` = AppSecret 失效。

> 只用离线功能（选题评估、稿件体检、配图、文风）**完全不需要凭据**。

## 二、建议改的地方

### 品牌名

品牌名本号出现在这些文件里，替换成你的号名：

| 位置 | 说明 |
|---|---|
| `.agents/skills/*/SKILL.md`（7 个） | 技能描述里写死了号名 |
| `tools/*.py`（6 个） | 脚本头部注释与品牌行 |
| `voice/风格卡.md` | 标题里 |
| `上下文.md` | 系统说明里 |

一条命令批量替换：

```bash
grep -rl "本号" .agents tools voice 上下文.md | xargs sed -i '' 's/本号/你的号名/g'
```

### 信源列表

改 `tools/scan_feeds.py` 顶部的 `FEEDS`：

```python
FEEDS = [
    ("IT之家",      "https://www.ithome.com/rss/"),
    ...
]
```

同时按你的领域调 `AI_KW`（入选关键词）和 `NOISE`（噪声词）。

> 当前 11 个源里有 3 个不可用：`VentureBeat`（429）、`机器之心`（RSS 空）、
> `HuggingFace Papers`（401）。换源时顺手清掉。

### 视觉与字体

`tools/make_figs.py` 和 `tools/wx_publish.py` 顶部：

```python
FONT_BOLD = "/System/Library/Fonts/STHeiti Medium.ttc"      # macOS
FONT_REG  = "/System/Library/Fonts/Hiragino Sans GB.ttc"
```

Linux / Windows 换成 `Noto Sans CJK`、`Source Han Sans` 或系统自带中文字体。
主色 `#3D5A80`（冷灰科技蓝）在 `BLUE/ACCENT` 常量里，改成你的品牌色即可。

### 平台规则

如果你不在微信公众号，**这三处要重写**：

| 位置 | 为什么要改 |
|---|---|
| `tools/preflight.py` 的 `BANNED_WORDS` / `STYLE_BANNED` | 各平台禁词不同 |
| `.agents/skills/ai-article-formatter/` | 排版语法、字数上限、图片规则都是微信口径 |
| `.agents/skills/ai-wechat-publish/` | 整节是微信 API 流程 |

**其他平台的适配思路**：`preflight.py` 的检查项是「列表 + 正则」结构，
加平台规则就是往列表里加词、往 `check()` 里加一段判断。

## 三、跑通验证

改完之后，按顺序验一遍：

```bash
# 1) 工具能跑
python3 tools/draft_kit.py brief                      # 应打印你的账号状态与风格卡

# 2) 选题能抓
python3 tools/topic_scan.py --hours 48 --top 5        # 应输出候选簇

# 3) 自检能过（拿任意一篇稿试）
python3 tools/preflight.py topics/你的稿子.md

# 4) 发布链路（不联网）
python3 tools/wx_publish.py formatted/你的稿.md --dry-run
```

## 四、清理工作数据

`topics/` `formatted/` `topic-scans/` `outputs/` `sources/` `reviews/` `kimi-test/`
`vidu-test/` `video/` 都是**本机工作数据**——是你的稿件、选题存档、一手源与渲染产物。

**要把它当模板分享给别人的话**，先清掉：

```bash
mkdir -p examples
# 每个目录留一份脱敏样例，删掉其余
rm -rf topics/* formatted/* topic-scans/* outputs/* sources/* reviews/*
rm -rf kimi-test vidu-test video assets
```

并确认：

```bash
# 没有账号私有数据（应无输出）
git grep -nE "粉丝数：[0-9]|日均收入：[0-9]|WX_APPSECRET=[A-Za-z0-9]"
# 没有微信真实链接（草稿箱图片的永久 URL）
git grep -c "mmbiz.qpic.cn"
```

## 五、已知坑（都是踩过的）

| 坑 | 现象 | 处理 |
|---|---|---|
| 微信 `draft/add` 成功不返回 `errcode` | 脚本误报失败 | 判断成功要用 `'media_id' in resp` |
| 系统 Python 3.13 的 SSL 链 | 直连微信 API 必挂 | 统一走 `curl`，不要用 `urllib`/`requests` |
| Markdown 图片语法的 `!` | 被当成感叹号误报 | 计数前先剥 `![...](...)` |
| `.agents/` 是只读保护区 | 改技能报权限错 | 需要显式批准一次写入 |
| `find` 扫大目录 | 被超时杀掉（exit 137）→ 误判"文件不存在" | 用 `ls` 直接看 |
| 多行代码块 | md2wx 不支持，会渲染成字面文本 | 一行一段连续写 |
| 封面装饰元素 | 压到标题字上 | 装饰固定靠边，与标题留安全距离 |
| `/tmp` 被系统清理 | 封面丢失 | 产物落 `outputs/` |
| 口语语料的"你"密度 | 文风体检报"比习惯少 50/千字" | 那是口语场景，**不迁移是刻意的**，不是偏差 |
